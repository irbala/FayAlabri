Building Arabic websites that read right to left

Most of my projects are in Arabic: an adhkar app, a perfume store, a coaching site for a client and travel guides for my family. Arabic reads right to left, and a page that simply translates English text into Arabic ends up feeling backwards. These are the six things I now do on every Arabic site.

1. Set the language and direction once, on <html>

Every Arabic page starts with this line:

<html lang="ar" dir="rtl">

dir="rtl" flips the whole layout: text aligns to the right, flex rows start on the right and lists put their bullets on the right. lang="ar" tells screen readers to use an Arabic voice and helps the browser choose the right font. Setting both on <html> means I don't have to fix direction element by element.

2. Keep numbers and English reading left to right

Inside right-to-left text, numbers and Latin text can get shuffled. A phone number like +966 56 394 7284 can show up with its parts in the wrong order. I wrap these in their own direction:

<a href="tel:+966563947284" dir="ltr">+966 56 394 7284</a>

In Athkar the counter ("2 / 32") and the English copyright line get the same treatment, so they always read naturally.

3. Mark the language of mixed text

My Edinburgh guide is bilingual. The page itself is English, and every Arabic label is wrapped in <span lang="ar">. Screen readers switch voice at the right moment, and the font stack falls back to an Arabic font for just those words.

4. Use logical CSS properties

margin-left means "left" in every language, which is wrong half the time on a bilingual site. margin-inline-start means "the side where the line starts", so it follows the text direction. In the Ateeq store the item count beside the cart link uses it, so the spacing is right without a separate RTL rule.

5. Flip arrows and icons that show direction

In a right-to-left app, "next" is on the left. Athkar's next button points left (←) and previous points right (→), and each button has an Arabic aria-label so screen reader users hear "التالي" and "السابق" instead of "arrow".

6. Choose the Arabic font on purpose

Arabic fonts carry a lot of the personality of a page. I pick them like I pick colours:

  • Noto Sans Arabic for long reading, like the adhkar text in Athkar
  • Noto Kufi Arabic for headings and a more structured feel, like the Ateeq store
  • Tajawal for a clean, modern look, paired with Playfair Display in my Bodrum guide

What I'd tell myself at the start

Design the Arabic version first, not as a translation of an English layout. Most RTL bugs come from treating right to left as an afterthought.
